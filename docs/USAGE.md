# 使用指南

适用于青听 1.7.0。

## 播放与本地音乐

在“搜索”页切换歌曲宝、MY FREE MP3 或下歌宝，输入歌名或歌手后选择播放或下载。MY FREE MP3 首次播放可能需要等待音频生成。

下载会检查响应类型和音频文件头。服务器返回网页、JSON 或空内容时不会加入曲库；链接失效会尝试重新解析一次，仍失败时可切换来源。暂停或重启后的续传会核对服务器返回的文件版本与断点范围，无法确认已完整的文件会重新完整下载。

下歌宝只支持页面公开的直接音频。出现浏览器验证或页面只有网盘分享时会显示提示；青听不会把分享页当作歌曲，也不自动处理网盘登录。不同网络下站点可用性可能不同。

下载完成的歌曲会进入“本地”页。已有音乐可在“设置”中扫描当前下载目录导入。每次扫描完成都会刷新“本地”列表，导入新歌曲并清理当前目录内文件已不存在的记录，同时更新收藏、歌单、最近播放及播放队列。本地搜索支持歌名、歌手、专辑、歌词、拼音和拼音首字母。点击列表上方的搜索按钮输入条件；已有搜索条件时，按钮显示为“清除搜索”，再点一次即可恢复完整歌曲列表，排序和搜索历史会保留。

点击底部播放栏打开歌词页，可点击歌词跳转或拖动进度条。播放队列支持调整顺序，下载任务支持暂停、取消和重试。

## 多选与歌单

点击列表工具栏的多选按钮，或长按歌曲进入多选；可全选当前列表，切换列表会清空选择。点击“加入歌单”选择已有歌单，或新建后批量加入。

“操作”菜单还支持批量收藏、取消喜欢、修改或清空专辑、删除记录和歌曲；在歌单内可批量移出歌曲。

- “本地 → 歌单”可导入歌单文件，或导出全部歌单；单个歌单的设置菜单可单独导出。
- 导入可新建或合并到已有歌单；重复歌曲去重，新建时重名自动加序号。
- `.qingting.json` 只保存歌单和歌曲信息，不包含音频、歌词或封面。
- 待匹配歌曲会保留，可在歌单内查看；歌曲下载或扫描入库后自动尝试匹配，也可再次导出。
- 同一歌曲有多个可能版本时，不会随意选择其中一个。
- 单次文件限制为 10 MiB、1000 个歌单、50000 首歌曲。

“删除记录”保留歌曲文件。删除文件时，Windows 和 Linux 使用回收站，Android 永久删除；操作前会显示确认提示。

## 北科云盘同步

在“设置 → 北科云盘歌曲同步（仅限 USTBer）”扫码登录，选择个人云盘文件夹，再开启自动同步或点击“立即同步”。

青听在选定目录内创建 `青听歌曲/` 和 `青听数据/`；根目录中的其他文件不会进入曲库。支持 MP3、FLAC、M4A、AAC、WAV、OGG。

歌曲和编辑后的歌曲信息可在设备间同步，歌单通过文件导入导出迁移。MP3 会同步文件标签，其他格式的编辑信息保存在青听中。

每次同步结束后会重新扫描当前下载目录并刷新本地曲库，已删除的歌曲会从“本地”及关联列表中移除。同步失败时也会尝试刷新本地文件状态。

同步失败时可查看失败清单，并只重试失败歌曲。两端音频内容冲突时保留冲突副本。

“同步删除歌曲”默认关闭。启用后，已同步歌曲在一端删除，会按云端确认结果同步到另一端；仅移除本地曲库记录不会触发云端删除。使用前请阅读应用内的影响说明。

登录凭据使用系统安全存储。Linux 需要已运行并解锁的 Secret Service 密钥环，例如 gnome-keyring。

## Windows 更新

在“设置 → 软件更新”的当前版本一行点击“检查更新”，发现新版后可下载。启动时默认检查并显示轻提示，可关闭“启动时检查更新”；下载和重启均由你手动确认。

下载完成后点击“重启并更新”，青听会暂停播放和下载任务，保存设置、歌单与播放队列，再升级并重新打开。原安装位置和个人文件会保留；新版启动失败时恢复旧程序。

从不带更新按钮的旧版本升级时，先运行一次新版安装包，选择原青听目录覆盖安装，无需手动删除。网络无法访问 GitHub 时，可通过发布页手动下载安装包。“打开发布页”位于设置中的“源代码”栏目；更新错误显示在当前版本旁，较窄窗口下自动换行。

## Android 权限

按需授予通知权限以显示媒体控制、悬浮窗权限以显示悬浮歌词，以及扫描公共存储目录所需的文件访问权限。

## Linux 安装与桌面功能

Ubuntu / Debian 安装下载的 DEB：

```bash
sudo apt install ./QingTing-*.deb
```

Arch 使用对应发行版的安装包：

```bash
sudo pacman -Syu
sudo pacman -U ./qingting-*.pkg.tar.zst
```

便携包解压后运行 `./qingting`，保留 `lib/` 和 `data/`。系统运行依赖见包内 README 或 [Linux 说明](../tools/linux/README.txt)。不同发行版的包应分别构建，不能直接互换。

- 托盘菜单可显示窗口、控制播放和退出。GNOME 需要 AppIndicator 扩展，KDE 原生支持托盘。
- 在“设置 → Linux 桌面”选择关窗后是否继续后台运行；无可用托盘时关窗退出。
- 支持 MPRIS 媒体快捷键，也可使用 `playerctl -p qingting` 控制播放。
- 使用 PipeWire 时，蓝牙自动暂停需要 `pipewire-pulse`。
- 歌单文件窗口需要 `xdg-desktop-portal` 和文件选择后端，如 GTK 或 KDE 后端。
- Linux 暂不支持桌面悬浮歌词。

## 搜索与网络排障

先在“设置 → 诊断与日志”查看对应错误，必要时复制诊断信息反馈。清空日志不会删除音乐或设置。

若浏览器能搜索、青听提示拒绝访问，可完全退出青听，暂时关闭代理（含 TUN）后重试。应用读取进程中的 `http_proxy`、`https_proxy`、`no_proxy`，不会自动继承浏览器扩展或 Cookie。

如关闭代理后恢复正常，请检查分流规则及音频域名的实际出口；HTTP 403 本身不能确定具体原因。调整网络后可直接重试。

若启动时提示数据文件和备份都无法读取，请先保留原文件，按提示修复存储权限或恢复备份后重试。
